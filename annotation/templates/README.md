# Annotation templates

`annotation_sheet_template.csv` documents the exact schema an annotator
receives. Real sheets are generated by
`scripts/annotation/create_annotation_sheet.py` and written to
`data/gold/annotation/` (gitignored — they contain corpus text).

## Annotator-facing columns

| Column | Filled by | Values |
|---|---|---|
| `id` | generated | stable candidate id, do not edit |
| `text` | generated | post text, do not edit |
| `label` | annotator | `explicit_crisis` / `implicit_crisis` / `hard_negative` / `non_crisis` |
| `confidence` | annotator | `high` / `medium` / `low` |
| `notes` | annotator | free text; required when confidence is `low` |

## Columns deliberately withheld

`stratum`, `src_risk`, `explicit_lex`, `explicit_terms`, `source` and
`src_meta` are written to `candidate_key.csv` instead, and are joined back only
after annotation is complete. Showing an annotator that an item was routed as
"likely implicit", or that it matched the crisis lexicon, would anchor exactly
the judgement the annotation is meant to produce independently.
